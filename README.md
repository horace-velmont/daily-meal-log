# 하루 식탁 · Daily Meal Log

날짜별로 식단과 칼로리를 기록하는 한국어 반응형 웹앱입니다.

- 하루 한 페이지: 이전·다음 날짜, 날짜 직접 선택, 오늘로 이동
- 아침·점심·저녁·간식별 음식 추가, 수정, 삭제
- 하루 총칼로리, 변경 가능한 일일 목표, 진행률
- 날짜별 메모 및 URL 날짜 유지 (`?date=2026-10-18`)
- 브라우저 localStorage 자동 저장, JSON 백업 내보내기·가져오기

## 실행

Node.js 의존성 설치 없이 실행합니다. Python 3가 필요합니다.

```sh
npm start
```

http://localhost:8000 에 접속합니다. HTML 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

## 검증

Node.js 18 이상에서 `npm test`로 날짜 경계, 합계, 백업 검증을 확인합니다.

## 데이터 보관

기록은 **현재 브라우저와 사이트 주소별로** 저장됩니다. GitHub에 식단 기록이 업로드되지 않으며 서버 동기화나 계정 로그인 기능은 없습니다. 브라우저 데이터 삭제 또는 시크릿 모드 종료 시 기록이 사라질 수 있으니 JSON으로 백업하세요. 백업 가져오기는 확인 후 현재 전체 기록을 교체합니다. 기본 2,000 kcal는 변경 가능한 초기 UI 값입니다.

## 배포

정적 파일 `index.html`, `style.css`, `app.js`, `model.js`를 정적 호스팅에 올리면 됩니다. 빌드는 필요하지 않습니다.
